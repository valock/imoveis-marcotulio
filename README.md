# Imóveis Marco Túlio — Landing Page

Landing page institucional de imóveis em Uberlândia, com seção de blog otimizada para SEO (novas regras da Caixa 2026, FGTS, Minha Casa Minha Vida) e diversos CTAs para WhatsApp.

🔗 **Ao vivo:** https://imoveis.marcotulio.pro

## Conteúdo
- `index.html` — página principal (HTML/CSS/JS em arquivo único)
- `sitemap.xml` — mapa do site para buscadores
- `robots.txt` — diretrizes de indexação

## Stack
Site estático. Sem build, sem dependências.

## Deploy
Publicado no **Netlify** (deploy manual). Para atualizar: edite os arquivos e faça novo deploy.
